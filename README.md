# Laptop Price Predictor

A machine learning project that predicts the price of a laptop based on its specifications such as brand, processor, RAM, storage, GPU, operating system, and display features.

## Features

* Predict laptop prices from user-provided specifications
* Data preprocessing and feature engineering
* Model training and evaluation using regression algorithms

## Technologies Used

* Python
* Pandas
* NumPy
* Scikit-learn

## Project Workflow

1. Collected and cleaned the laptop dataset
2. Performed feature engineering and preprocessing
3. Trained multiple regression models
4. Evaluated model performance using standard regression metrics


## Purpose

This project was built to practice the complete machine learning workflow, including data preprocessing, model development and evaluation
